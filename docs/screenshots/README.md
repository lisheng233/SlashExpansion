## 规格建议

- 分辨率 1920×1080 或更高，PNG。
- 单张控制在 **1.5 MB 以内**（GitHub 加载快，也便于国内访问）。太大可以用 `pngquant` 或截图工具压缩。
- 构图尽量包含「技能特效 + 刀 + 少量环境」，别只有一片粒子。
- 对比度：夜晚/地下截图记得带光源，否则特效看不清。
