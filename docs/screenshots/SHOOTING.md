# 截图拍摄清单

按这个顺序拍，每张都能一次过。所有 SA 都可以用命令直接播放，不必真的打架。

## 准备

1. 创造模式，选一个开阔、光照均匀的地方（平原 / 沙漠 / 灵魂沙峡谷都行）。
2. `F1` 隐藏 HUD；`F2` 截图（存到 `screenshots/`）。
3. 打开 `[vfx] enabled = true`、`particleScale = 1.0`、`screenShake = false`（避免拍出来是糊的）。
4. 建议固定时间：`/time set noon`，`/weather clear`。
